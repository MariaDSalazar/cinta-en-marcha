# Cinta en Marcha

Cinco zonas de lógica en la cinta de equipaje de un aeropuerto ficticio: decidir qué maletas pasan la reja, desarmar piezas que dependen unas de otras, armar moldes justos, seguir la cuenta de un estante y resolver casos con pocas pruebas.

Se abre `index.html` en el navegador del celular o del computador, sin instalar nada. Cada zona empieza con un ejemplo resuelto que se mueve solo.
